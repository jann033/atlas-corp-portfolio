# X HEART UZ — fashion Mini App prototype

Interactive portfolio prototype by Djannik Aliev / ATLAS CORP.

12 sample products, drops, looks, catalogue search and filters, size selection, favourites, cart, checkout, illustrative receipt upload and order-status views. Russian/Uzbek interfaces and light/dark themes. Cart and orders are browser-local; receipt images are saved locally in IndexedDB.

Orders and receipts are not sent to a store. Payment details are examples; no payment gateway or order-processing backend is connected. Use test data only.

Product and look photography includes AI-generated images and reference photographs supplied by the project author. These are demonstration assets, not documentation of a live inventory.

Open index.html through any static HTTP server. The img directory must remain alongside it.
