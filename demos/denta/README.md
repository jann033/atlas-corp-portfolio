# DENTA — dental clinic interface demo

Portfolio demonstration by ATLAS CORP / Djannik Aliev. Browser-based interactive prototype, not a production medical-record system.

Includes a seeded set of 24 fictional patients, search and filters, patient cards, dental chart, treatment and payment views, registration, scheduling, staff/patient demo modes and themes. Changes are stored in this browser's localStorage. No clinic backend, production authentication or real payment processing is connected.

Use fictional information only. All initial patient records are generated by the source-code seed() function. Do not use this public demo for actual patient information.

Open index.html through any static HTTP server.
